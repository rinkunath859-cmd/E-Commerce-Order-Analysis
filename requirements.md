# Requirements

## Software Requirements

The following software is required to run this project:

- Microsoft Power BI Desktop (Latest Version)
- Microsoft Excel (2016 or later)
- Windows 10/11 (64-bit)
- Git (Optional, for version control)
- GitHub Account (Optional, for project hosting)

---

## Hardware Requirements

### Minimum Requirements

- Processor: Intel Core i3 (or equivalent)
- RAM: 4 GB
- Storage: 2 GB free disk space
- Display Resolution: 1366 × 768

### Recommended Requirements

- Processor: Intel Core i5/i7 (or equivalent)
- RAM: 8 GB or higher
- Storage: SSD with 5 GB free space
- Display Resolution: 1920 × 1080

## How to Run the Project

1. Clone or download this repository.
2. Open **Sales_Performance_Dashboard.pbix** using Microsoft Power BI Desktop.
3. If prompted, update the data source path to the local Excel dataset.
4. Click **Refresh** to load the latest data.
5. Explore the dashboard using slicers, drill-through pages, bookmarks, and interactive visuals.
