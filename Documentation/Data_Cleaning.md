# Data Cleaning

## Power Query Steps

- Imported Orders, Customers and Sales Targets tables.
- Checked data types.
- Removed duplicate records.
- Identified missing Order Source values.
- Found first and last timestamps of missing values.
- Replaced missing Order Source using Mode/Fill Down based on transaction sequence.
- Created Sales Manager column by merging First Name and Last Name.
- Validated Customer IDs and Sales POC mappings.
